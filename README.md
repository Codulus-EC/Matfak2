# Математический факультет ВГУ — редизайн сайта

Учебный/проектный редизайн сайта математического факультета ВГУ. Проект собран на **Next.js + React + TypeScript** и содержит главную страницу, раздел для школьников и архив олимпиадных материалов.

## Что уже есть

- крупный hero и адаптивная навигация;
- блок «Почему выбирают Матфак?»;
- программы обучения с переключением уровней;
- события и FAQ;
- контакты и карта;
- отдельная страница **«Школьникам»**;
- региональная олимпиада и школа олимпиадной математики;
- расписание занятий;
- архив примеров/решений задач;
- архив результатов прошлых лет;
- отдельный маршрут архива задач.

## Маршруты

- `/` — главная;
- `/schoolchildren` — школьникам;
- `/schoolchildren/tasks` — архив задач и решений.

## Стек

- Next.js 15
- React 19
- TypeScript
- CSS Modules + глобальные CSS-стили

## Локальный запуск

Нужен **Node.js 20+**.

```bash
cd frontend
npm install
npm run dev
```

После запуска откройте:

```text
http://localhost:3000
```

На Windows также можно запустить `START_SITE.bat` из корня репозитория.

## Проверка перед публикацией

```bash
cd frontend
npm ci
npm run typecheck
npm run build
```

## Публикация

Для быстрого публичного превью удобно использовать **Vercel**:

1. Создать репозиторий на GitHub и загрузить туда содержимое этой папки.
2. Импортировать репозиторий в Vercel.
3. В настройках проекта указать **Root Directory: `frontend`**.
4. Framework Preset: **Next.js**.
5. Deploy.

После этого появится публичная ссылка, которую можно отправлять другим людям.

## Структура

```text
.
├── frontend/
│   ├── app/                 # маршруты Next.js и глобальные стили
│   ├── components/          # компоненты интерфейса
│   ├── lib/                 # данные и вспомогательная логика
│   ├── public/              # изображения и статические ресурсы
│   ├── package.json
│   └── package-lock.json
├── backend/                 # заготовка под будущий REST API
├── .github/workflows/ci.yml # проверка typecheck + build на GitHub
├── .gitignore
├── START_SITE.bat
└── start-site.sh
```

## Backend

Текущая версия проекта ориентирована на frontend. Папка `backend/` оставлена как заготовка для следующего этапа: REST API, новости, программы, документы, результаты, расписание и контакты.
